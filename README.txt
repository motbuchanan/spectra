SPECTRA — install on your phone
================================

The files in this folder are a complete installable web app (PWA).
They must be served over HTTPS to install and to work offline — opening
index.html as a local file will NOT give you the install option. Use
GitHub Pages like your other projects.

DEPLOY (GitHub Pages)
---------------------
1. Put ALL of these files together in one folder of a Pages repo, e.g.
   a "spectra" folder in your motbuchanan.github.io repo:
       index.html
       manifest.webmanifest
       sw.js
       icon-180.png
       icon-192.png
       icon-512.png
       icon-512-maskable.png
2. Commit and push.
3. It goes live at:  https://motbuchanan.github.io/spectra/
   (All paths are relative, so any subfolder works.)

INSTALL ON PHONE
----------------
- iPhone (Safari): open the URL, tap Share, then "Add to Home Screen."
- Android (Chrome): open the URL, tap the menu, then "Install app"
  (or accept the install prompt).
Launch it from the home-screen icon — it runs full screen, works
offline, and keeps your sessions on the device.

YOUR DATA
---------
- Sessions are saved in this app's local storage on the phone. The app
  also asks the browser to mark that storage "persistent" so it isn't
  cleared automatically.
- The notes themselves are generated by the app every time — there are
  no audio files, so nothing audio-related can be lost.
- EXPORT writes all your sessions to a .json file (back this up).
- IMPORT reads a .json back in and merges it (matches by session id, so
  re-importing won't create duplicates). Use it to move data to a new
  phone or restore a backup.

UPDATING THE APP LATER
----------------------
If you change the files, bump the CACHE name in sw.js (e.g. 'spectra-v2')
so phones pick up the new version instead of the cached old one.
